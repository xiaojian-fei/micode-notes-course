# 小米便签使用指南

适用于本课程项目的维护版。实际程序界面为英文，本文按钮和功能名称采用“English（中文释义）”写法。本文按当前菜单资源和 Activity 处理逻辑核对，包含原有操作及 F1 置顶、F2 组合筛选、F3 内容统计。未维护基线只有原有功能。

## 1. 先打开应用

模拟器已安装应用时，在应用列表点击 Notes（小米便签）。命令行操作需要先定位自己电脑上的 ADB。

### 定位本机 ADB

在 Android Studio 的 SDK Manager 中查看 Android SDK Location（SDK安装位置），并确认 SDK Tools 中已安装 Android SDK Platform-Tools。

- 已将 SDK 的 platform-tools 目录加入 PATH 时，PowerShell 执行 `adb version` 应显示版本。
- 已设置 ANDROID_HOME 或 ANDROID_SDK_ROOT 时，下方脚本可直接使用该 SDK。
- 两者均未配置时，先将下面示例路径替换为 SDK Manager 显示的实际路径，再执行。仅在当前 PowerShell 窗口生效。

```powershell
# 可选配置。仅在环境变量及 PATH 均未配置时，替换为自己的真实 SDK 目录后执行。
$env:ANDROID_HOME = 'C:\替换为自己的SDK目录'
```

在 PowerShell 执行以下脚本定位 ADB。

```powershell
$adbCommand = Get-Command adb -ErrorAction SilentlyContinue
if ($adbCommand) {
    $adb = $adbCommand.Source
} else {
    $sdkPath = $env:ANDROID_HOME
    if (-not $sdkPath) { $sdkPath = $env:ANDROID_SDK_ROOT }
    if (-not $sdkPath) { throw '请先配置本机 SDK 路径，或把 platform-tools 加入 PATH。' }
    $adb = Join-Path $sdkPath 'platform-tools/adb.exe'
    if (-not (Test-Path -LiteralPath $adb)) { throw 'SDK 路径下找不到 adb.exe，请检查路径及 Platform-Tools。' }
}
& $adb devices
```

启动自己的模拟器，等它进入系统。将下面的设备号替换为 `devices` 输出中状态为 `device` 的实际设备号，再启动应用。

```powershell
$serial = 'emulator-5554'  # 示例，替换为自己实际的设备号
& $adb -s $serial shell am start -n net.micode.notes/.ui.NotesListActivity
```

下文命令沿用同一 PowerShell 窗口中的 `$adb` 和 `$serial`。首次构建、安装及 SDK 配置见本仓库 [README](../README.md)。

## 2. 找不到菜单时怎样打开

**菜单默认隐藏。先点击模拟器画面，让模拟器获得键盘焦点，再按 Ctrl＋M，即可打开当前页面的菜单。** 首页和便签编辑页会显示不同的菜单。

若 Ctrl＋M 没有响应，可以使用下列 ADB 菜单键命令。

1. 先让模拟器停在需要操作的页面。
2. 在 PowerShell 执行以下命令。
3. 回到模拟器，在弹出的菜单中点选功能。菜单通常显示在屏幕下方，项目较多时可上下滚动。

```powershell
& $adb -s $serial shell input keyevent 82
```

`82` 是 Android 菜单键，与 Ctrl＋M 用于打开同一类选项菜单。优先在模拟器中按 Ctrl＋M，命令作为备用入口。

| 当前页面 | 怎样进入 | 菜单中的主要功能 |
| --- | --- | --- |
| 首页列表 | 启动应用后看到一条条便签或文件夹 | Filter notes（组合筛选）、New Folder（新建文件夹）、Search（搜索）、Export text（导出文本）、Sync（同步）、Settings（设置） |
| 普通便签编辑页 | 在列表点开便签，或点底部“＋ Add note（写便签）” | Content statistics（统计）、Pin note / Unpin note（置顶/取消）、Add note（新建）、Delete（删除）、Font size（字号）、Enter check list（清单）、Share（分享）、Remind me（提醒）等 |
| 文件夹内部 | 在首页点开文件夹 | 使用该目录的列表菜单，选项可能比首页少 |

要使用组合筛选或新建文件夹，先返回首页。要使用置顶、统计或提醒，先打开一条普通便签。长按文件夹弹出的上下文菜单是另一个入口，用于查看、删除和改名。

## 3. 新建、编辑与保存

1. 在首页点底部“＋ Add note（写便签）”。
2. 点正文区域，输入实际内容，例如“今天完成软件工程报告”。
3. 点击屏幕底部 Android 返回键，即左侧三角形。
4. 如果只收起了键盘，再按一次，直到回到便签列表。
5. 在列表点开刚才的便签，确认文字保留。
6. 修改文字后，同样返回列表并重新打开检查。

保存由编辑页的返回和暂停流程触发。空白新便签会被忽略。颜色或字号选择面板展开时，返回键可能先关闭面板，继续返回到列表再检查结果。

若列表看不到刚保存的内容，先确认当前是否在另一个文件夹、是否有筛选或搜索条件。清除条件并回到创建时的目录查找。如果重新打开后正文确实丢失，保留输入内容、操作步骤及当前版本信息，作为异常反馈。

## 4. 删除、文件夹与移动

### 删除一条便签

打开该便签，按 Ctrl＋M 打开菜单，选择“Delete（删除）”，核对确认框后确认。也可以在列表长按普通便签进入选择模式，勾选目标后点删除。删除前确认自己选中的对象。

### 创建文件夹

1. 返回首页，按 Ctrl＋M 打开菜单。
2. 点“New Folder（新建文件夹）”，输入“课程演示”等有效名称。
3. 点 OK（确认），在列表中找到并打开新文件夹。

维护版会去除名称前后的空白，并检查重复名称。空字符串和全空白名称无法保存。历史数据中的空白文件夹可能仍然显示，可按需要改成有效名称。

### 修改文件夹名称

在首页长按目标文件夹，在弹出的菜单中选择“Change folder name（修改文件夹名称）”，输入新名称后点 OK（确认）。普通便签长按进入的是选择模式，操作对象应先看清。

### 将便签移入文件夹

在列表长按普通便签进入选择模式，勾选需要移动的便签，点“Move to folder（移动到文件夹）”，在目标列表选择文件夹。完成后进入目标文件夹，检查便签位置。返回键可退出选择模式。

在文件夹内部点“＋ Add note（写便签）”，可直接在该目录创建便签。

## 5. 搜索正文

1. 回到首页，按 Ctrl＋M 打开菜单，选择“Search（搜索）”。
2. 输入正文中实际存在的词，例如“课程”或 `alpha`。
3. 输入过程中可点击搜索建议直接打开便签。
4. 也可以按输入法的搜索键提交，再从结果列表打开便签。
5. 打开结果后，观察正文中的匹配高亮。

维护版按普通文本匹配，`%`、`[`、反斜杠等字符可以直接搜索。英文 ASCII 大小写可匹配，例如 `alpha` 对应 `ALPHA`。建议点击与直接提交是两条入口，操作时按实际使用的路径观察。

搜索无结果时，先确认样本文字确实存在。使用返回键退出搜索页面；如果列表仍显示搜索结果，退出该列表并重新进入首页再浏览。

## 6. F1 置顶与取消置顶

1. 创建两条有内容的普通便签。
2. 打开要置顶的一条，按 Ctrl＋M 打开菜单。
3. 选择“Pin note（置顶便签）”，返回列表。
4. 观察便签上的“↑ PIN（置顶）”标识，以及它在便签中的排序。
5. 再打开这条便签，按 Ctrl＋M 打开菜单，选择“Unpin note（取消置顶）”。
6. 返回列表，确认标识消失。

文件夹保持原有排序规则，置顶便签排在普通便签前面。置顶状态会保存，可关闭并重新打开应用检查。

## 7. 修改便签背景颜色

1. 打开普通便签。
2. 点击正文上方标题栏右侧的颜色按钮，展开颜色选择。
3. 点选需要的颜色，例如蓝色。
4. 返回列表保存，并重新打开确认颜色。

颜色按钮属于编辑页面自身，进入菜单前可先收起颜色面板。设置过颜色的便签可以作为下一节组合筛选的样本。

## 8. F2 组合筛选

先准备“课程演示”文件夹，在里面创建一条蓝色便签和一条其他颜色便签。按第7节设置颜色。

1. 返回首页，按 Ctrl＋M 打开菜单，选择“Filter notes（组合筛选）”。
2. 在 Folder（文件夹）中选“课程演示”。
3. 在 Color（颜色）中选“Blue（蓝色）”。
4. 在 Modified from (inclusive)（开始日期，含当天）和 Modified through (inclusive)（结束日期，含当天）中按 `YYYY-MM-DD` 输入，使用模拟器显示的日期，例如 `2026-11-12`。
5. 点“Apply（应用）”，观察同时满足条件的便签。
6. 点开结果编辑，再返回，观察结果刷新。
7. 再次打开“Filter notes（组合筛选）”，在对话框中点“Clear filters（清除筛选）”，恢复普通列表。

条件可单独使用或组合使用，日期可留空。开始日期应早于或等于结束日期。日期针对便签的修改时间，首尾日期按整天处理，使用设备时区。空结果时，重新打开筛选对话框放宽条件或清除筛选。

## 9. F3 正文与清单统计

### 统计当前正文

1. 新建或打开便签，输入中文、英文或 Emoji。
2. 留在编辑页，按 Ctrl＋M 打开菜单，选择“Content statistics（内容统计）”。
3. 查看 Characters (Unicode code points)（Unicode码点字符数）和 Logical lines（逻辑行数）。
4. 关闭弹窗，追加文字，再打开统计观察变化。

统计读取当前编辑内容，支持尚未返回列表的文字。字符以 Unicode 码点计数，换行计入字符数。正文行数按逻辑换行计算，屏幕宽度造成的自动折行不会增加逻辑行。

### 切换清单并查看完成率

1. 在普通便签输入三行内容，例如“买书”“复习”“提交作业”。
2. 按 Ctrl＋M 打开菜单，选择“Enter check list（进入清单模式）”，三行文字转换为可勾选条目。
3. 打开“Content statistics（内容统计）”，查看 Valid checklist items（有效条目数）、Completed（完成数）和 Completion（完成率）。
4. 勾选一项，再查看统计；三项完成一项时约为33.3%。
5. 全部勾选后再查看，完成率为100%。

菜单中的模式切换项会随状态变化，切换回普通模式时选择“Leave check list（退出清单模式）”。

## 10. 设置和取消提醒

1. 打开有内容的普通便签，按 Ctrl＋M 打开菜单。
2. 选择“Remind me（提醒我）”，设置未来日期及时间。
3. 核对时间控件和对话框标题，点 OK（确认）。
4. 检查编辑页上方的提醒时间，再返回列表保存。
5. 已有提醒时，打开菜单选择“Delete reminder（删除提醒）”即可取消。

演示可选择“明天08:15”，避开已经过去的时间。系统12/24小时制在模拟器系统设置的日期和时间页面中调整，具体入口取决于 Android 版本。

要验证实际触发，可设置未来1～2分钟的提醒，保持设备运行，等待真实弹窗。声音需检查模拟器音频和系统音量。工作区旧的一键启动脚本使用了 `-no-audio` 参数，通过它启动的模拟器不适合试听提醒声。

## 11. 常见问题速查

| 现象 | 先做什么 |
| --- | --- |
| 顶部看不到三个点或功能菜单 | 停在目标页，点击模拟器后按 Ctrl＋M，或执行第2节备用命令 |
| 菜单里没有置顶或统计 | 先打开普通便签，再打开菜单；确认安装的是维护版 |
| 菜单里没有组合筛选或新建文件夹 | 退出编辑页、选择模式和文件夹，回到首页再打开菜单 |
| 按返回仍在编辑页 | 看是否刚收起键盘、颜色或字号面板，再返回到列表 |
| 新建后找不到便签 | 输入有效正文，返回列表，检查所在文件夹与筛选条件 |
| 筛选后空白 | 检查文件夹、颜色、修改日期及设备日期，或在筛选对话框清除条件 |
| ADB 提示多个设备 | 用 `devices` 查看设备号，每条命令加 `-s 实际设备号` |
| ADB 无设备或显示 offline | 启动模拟器并等待进入系统，重新执行 `devices` |

## 12. 第一次操作建议顺序

新建一条便签，返回列表并重新打开确认保存。接着按 Ctrl＋M 打开菜单，完成一次置顶与取消置顶，再查看内容统计。最后创建文件夹、设置颜色并做一次组合筛选，即可熟悉本项目的主要入口。

本指南于2026年11月12日按当前源码和菜单资源核对。本次新增文档未进行设备实测，实际设备存在差异时按屏幕表现记录并反馈。
