## 使用Git协作

队友尚未被邀请为collaborator时，可先Fork本仓库，再从个人Fork发Pull Request。获得写权限后也应使用各自分支：

```powershell
git switch main
git pull --ff-only
git switch -c review/corrective-tests
# 新增自己的复核记录后，只添加实际改动文件
git add docs/reviews/你的记录.md
git commit -m "记录纠正性维护独立复测结果"
git push -u origin review/corrective-tests
```

新增功能复核可使用 `review/feature-demo` 等独立分支。公开仓库只提交无个人信息的复核说明；含姓名学号的报告、密钥、数据库和完整本地日志私下交接。不要修改旧提交的作者或时间。
